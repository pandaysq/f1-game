# Физика (заполняется по фазам)

Правило master prompt: каждая формула — с комментарием (смысл + единицы), все
константы — в data-файлах, не в коде.

## Единицы и соглашения

| Величина | Единица | Заметки |
|---|---|---|
| Масса | кг | болид + пилот, стартовое значение задаёт data-файл |
| Длина | м | колесная база, колея, ширина трассы |
| Скорость | м/с | в HUD конвертируется в км/ч |
| Сила | Н | продольные/боковые силы шин |
| Момент | Н·м | двигатель на колесах после редуктора |
| Углы | рад (внутри), град (в доках) | slip angle, поворот руля |
| Время | с | шаг физики dt = 1/120 |

Соглашение осей Godot: вперёд — **−Z** машины, вправо — +X, вверх — +Y.

## Структура констант (фаза 1)

Все константы лежат в `assets/data/vehicle.json` (черновой состав):

- кузов: масса, инерция (диагональная), высота ЦТ, колесная база, колея,
  развесовка;
- подвеска: жёсткость/демпфирование на колесо, прогрессивность, ARB спереди/сзади,
  ходы;
- рулевое: максимальный угол, зависимость лока от скорости;
- двигатель: кривая момента (пары rpm→Н·м), отсечка, трение;
- трансмиссия: 8 пар передаточных чисел, время переключения, финальная пара;
- тормоза: максимальное усилие, bias (перекос перед/зад);
- шины: параметры упрощённого Pacejka, load sensitivity, μ по поверхностям.

## Модель шин — базовая (фаза 1)

Упрощённая «magic formula» (Pacejka-lite):

- продольная сила от slip ratio, боковая от slip angle;
- комбинированный снос (friction circle): F = min(Fmax, sqrt(Fx² + Fy²));
- load sensitivity: μ падает с ростом вертикальной нагрузки;
- вертикальная нагрузка = статика + перенос веса от подвески.

Точная форма формул появится здесь при реализации фазы 1 — вместе с юнит-тестами,
которые их проверяют.

## Детерминизм

- Фиксированный шаг 120 Hz; никакой зависимости симуляции от FPS.
- Одинаковые входы + seed → побайтово одинаковый траектория/тайминги (тест фазы 1).
- Float-детерминизм гарантируем в рамках одной платформы; между платформами —
  допуск в тестах, оговорка честно документируется.

## Тоннелирование коллизий

При 300 км/ч (~83 м/с) шаг 120 Hz даёт ~0.7 м за тик: против ширины трассы 12+ м
запас есть, но тонкие поребрики требуют непрерывных рейкастов подвески и
достаточной толщины геометрии (правило для генератора трассы: поребрик ≥ 8 см
по вертикали collision-меша).
