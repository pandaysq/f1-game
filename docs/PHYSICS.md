# Физика

Правило master prompt: каждая формула — с комментарием (смысл + единицы), все
константы — в data-файлах (`assets/data/vehicle.json`), не в коде.

## Единицы и соглашения

| Величина | Единица | Заметки |
|---|---|---|
| Масса | кг | болид 750 кг, тело RigidBody3D |
| Длина | м | колесная база 3.1, колея 1.9 |
| Скорость | м/с | в HUD конвертируется в км/ч (×3.6) |
| Сила | Н | продольные/боковые силы шин |
| Момент | Н·м | двигатель, тормоза, колесо |
| Углы | рад | slip angle, поворот руля; в доках град |
| Время | с | шаг физики dt = 1/120 |

Соглашение осей: вперёд — **−Z** машины, вправо — +X, вверх — +Y. Начало координат
кузова — плоскость крепления колёс; центр масс ниже (0.30 м) — задается
`center_of_mass`.

**Демпфирование Godot отключено** (`default_linear_damp = 0`,
`default_angular_damp = 0`): дефолтные 0.1 — это скрытый тормоз, зависящий от
скорости. Всё сопротивление движению — только наша аэродинамика и потери в
шинах/подшипниках.

## Ядро машины (Phase 1)

RigidBody3D + 4 raycast-колеса (FL, FR, RL, RR). `VehicleBody3D` не используется
(D-002) — модель своя, тюнингуемая.

### Подвеска (raycast, на колесо)

- Сжатие: `c = (rest_length + radius) - distance_to_hit`, клампится в
  `[0, max_compression]` [м].
- Сила пружины: `F_spring = k·c + c_damper·dc/dt` [Н], где k = 120000 Н/м,
  c_damper = 8000 Н·с/м. `max(F, 0)` — пружина не тянет.
- Антиролл-бар: `F_arb = k_arb·(c_left - c_right)` [Н], k_arb = 18000 Н/м —
  противодействует разнице сжатий пары колес одной оси.
- Сила прикладывается вверх по оси кузова в точке крепления.
- Перенос веса — следствие геометрии (силы подвески прикладываются к кузову),
  не отдельной формулы.

### Рулевое

- Максимальный угол зависит от скорости: `δ_max(v) = lerp(0.55, 0.09, v/80)`
  [рад] — на скорости руль «длиннее».
- Скорость поворота ограничена (4.5 рад/с) — `move_toward` к целевому углу.
- Steering assist дополнительно сжимает угол на скорости.

### Двигатель и трансмиссия

- Кривая момента: пары [rpm, Н·м] = [(3000,320), (6000,380), (9000,400),
  (11000,380), (13000,330)], линейная интерполяция.
- Отсечка: при rpm ≥ 13000 момент = 0.
- 8 передач + задняя (ratio -2.8), финальная пара 3.4, время переключения 0.15 с
  (в переключении момент = 0).
- Момент на колесе: `T_wheel = T_engine · ratio · final / 2` [Н·м] (на каждое
  заднее колесо).
- rpm от колёс: `rpm = |ω_rear| · ratio · final · 60 / (2π)`; на месте —
  проскальзывание сцепления до launch_rpm 7000.
- Авто-КПП: вверх при wheel_rpm ≥ 0.94·redline, вниз при ≤ 0.45·redline.

### Колесо (динамика вращения)

`I·dω/dt = T_drive − F_x·r − sign(ω)·T_brake − c_spin·ω` [Н·м], где I = 1.4
кг·м² (колесо + приведённая трансмиссия), c_spin = 0.4 Н·м·с — потери в
подшипниках/трансмиссии. Фиксированный шаг 1/120 с.

### Тормоза

- Максимальный момент 4000 Н·м, перекос bias 0.58 на переднюю ось (на колесо:
  `T_brake = T_max · input · bias_axis · 0.5`).
- Тормоз не может сменить знак ω внутри одного тика: при |ω| меньшем шага и
  нулевой тяге колесо ставится в 0.

## Шины (Phase 1, упрощённый Pacejka)

«Magic formula»: `F = Fz · μ · sin(C · atan(B · s))`

- Продольная: s = slip_ratio = `(ω·r − v_forward) / max(|v_forward|, 1)` [-].
- Поперечная: s = slip_angle = `atan2(v_side, max(|v_forward|, 1))` [рад].
- Параметры: lat B=8.5 C=1.6, lon B=10 C=1.65, μ = 1.65 (обе оси).
- Load sensitivity: `μ_eff = μ · (1 − 0.05·(Fz/2000 − 1))`, клампится в
  [0.3·μ, μ] — сцепление падает с ростом нагрузки.
- **Релаксационная длина 0.15 м** — продольный slip интегрируется как состояние
  первого порядка: `s_state ← lerp(s_state, s_target, dt·|v|/σ)`. Это физика
  контакта (пятно нужно расстояние, чтобы набрать силу) и стабилизатор
  колесного контура на 120 Гц. Поперечный slip — мгновенный (лаг угла
  раскачивал рысканье, см. KNOWN_ISSUES).
- Комбинированный снос (friction circle): `|F| = min(√(Fx²+Fy²), μ·Fz)` — при
  превышении обе силы масштабируются.
- μ поверхности из данных трассы: асфальт 1.0, поребрик 0.95, трава 0.55,
  гравий 0.45, барьер 0.25 (meta «grip» на StaticBody3D).

## Аэродинамика (Phase 1, базовая)

- Сопротивление: `F_drag = 0.48 · v²` [Н] — против вектора скорости.
- Прижимная сила: `F_down = 1.0 · v²` [Н] — вниз (упрощение; крылья и баланс —
  фаза 2 по плану).

## Ассисты (индивидуальные тумблеры, дефолт — вкл)

- **Traction control**: момент тяги масштабируется
  `lerp(1, 0.1, clamp((slip_rear − 0.15)/0.25))` — плавно гасит пробуксовку за
  пиком сцепления (~slip 0.14).
- **ABS**: тормозной момент масштабируется аналогично при slip < −0.25.
- **Auto gearbox**: перекл. передач по wheel_rpm (см. трансмиссию).
- **Steering assist**: сжимает максимальный угол руля на скорости.
- **Stability control**: управляющий момент рысканья `−2.5·m·0.01·ω_yaw`.

## Детерминизм

- Фиксированный шаг 120 Hz; симуляция не зависит от FPS.
- Одинаковые входы + seed → одинаковые состояния (тест: два прогона разгона —
  идентичные позиция и скорость).
- Гарантия в рамках одной платформы; между платформами — допуски (оговорка).

## Тоннелирование коллизий

300 км/ч ≈ 83 м/с ≈ 0.7 м за тик при 120 Hz. Подвеска — непрерывные рейкасты
(луч длиннее хода подвески на радиус колеса), поребрики ≥ 8 см по вертикали в
collision-меше (правило генератора трассы).

## Что упрощено (честно)

- Колесо — точка контакта без ширины и camber/toe (фаза 5/8).
- Задний дифференциал — жестко общий (open/locked — сетап фазы 8).
- Аэродинамика без грязного воздуха и slipstream (фаза 2).
- Температуры/износ шин, топливо — фаза 5.
