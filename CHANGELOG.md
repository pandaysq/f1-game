# Changelog

Формат — Keep a Changelog; версии семантические, привязка к фазам роадмапа.

## [0.2.0] — 2026-11-21 — Phase 1: одна машина, одна трасса, Time Trial

### Added
- Формат трасс (JSON v1) + валидатор: замкнутость, самопересечения, ширина,
  тайминг-линии, spawn; CI-проверка каждой трассы.
- Трасса `alpha_loop.json`: 130 точек, ~1.24 км, вымышленный лэйаут.
- Генератор трассы: полотно, поребрики (красно-белые, на кривых), барьеры,
  гравий/трава, старт-финиш; коллизии с grip по поверхностям.
- Болид: RigidBody3D + 4 raycast-колеса; подвеска (пружина/демпфер/ARB),
  перенос веса, speed-sensitive руль, кривая момента, 8 передач + задняя,
  отсечка, brake bias; упрощённый Pacejka с load sensitivity и релаксационной
  длиной; аэродинамика (drag + downforce); все константы в vehicle.json.
- Time Trial: круги, секторы (3), текущее/последнее/лучшее время, сохранение
  лучшего круга в user://best_times.json.
- Кокпит-камера (основная) + chase (V), HUD (скорость/передача/круг/время),
  тач-контролы (руль/газ/тормоз/нитро) для мобильного таргета.
- Ассисты: авто-КПП, TC, ABS, steering assist, stability control (тумблеры).
- Тесты: 41 проверка — конфиг, валидатор (включая сломанные трассы), логика
  тайминга (круги/секторы/защита от «маятника»/персистентность), физика
  (детерминизм, нет скорости из ниоткуда, тормозной путь 300→100 в ожидаемых
  рамках 190 м, симметрия лево/право 1.2%).

### Fixed
- Знак поперечной силы шины (был анти-гасителем → раскачка рысканья).
- Скрытое демпфирование Godot (0.1) отключено — аэродинамика теперь единственный
  источник сопротивления.
- Стабильность колесного spin-контура (релаксационная длина + плавные TC/ABS).
- Визуальный QA через программный рендер (xvfb + GL): найдено и починено —
  winding квадов (дорога/кербы/юбка были невидимы сверху), погребённая под
  травой половина трассы (elevation −2.5..+2.5 при плоскости y=0 → юбка-отсек),
  ступенька высот на шве старт-финиша (1.8 м из-за незамкнутого синуса
  elevation), косой спавн-базис (Basis(RIGHT, UP, -dir) не ортонормирован:
  перекос машины и разгрузка диагонали колёс), кокпит-камера не следовала за
  машиной (снимала мировой ноль), обрезанные HUD-метки справа.

## [0.1.0] — 2026-11-20 — Phase 0: Foundation

### Added
- Роадмап фаз 0–9 и скелет документации (PLAN, ARCHITECTURE, DECISIONS, PHYSICS,
  KNOWN_ISSUES).
- Каркас Godot 4.5.1: физика 120 Hz, Input Map (клавиатура), autoload Settings,
  main-сцена с дебаг-оверлеем (FPS, тик физики, F3).
- Headless smoke-тесты конфигурации и валидатор трасс.
- CI на GitHub Actions: gdformat/gdlint, headless-импорт, валидатор, тесты.
