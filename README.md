# Apex GP

Open-wheel racing game for friend leagues (working title). Fictional teams,
drivers and tracks only — no real-world brands.

**Engine:** Godot 4.5.1 · **Target:** mobile (Android/iOS, Mobile renderer) ·
**License:** MIT · **Roadmap:** [docs/PLAN.md](docs/PLAN.md)

[![CI](https://github.com/pandaysq/f1-game/actions/workflows/ci.yml/badge.svg)](https://github.com/pandaysq/f1-game/actions/workflows/ci.yml)

## Что это

Гонка с открытыми колёсами для дружеских лиг. Сейчас (Phase 0) — каркас проекта;
далее по роадмапу: одиночный Time Trial → гонки против AI → онлайн-лиги →
зрители/комментатор → шины/пит-стопы/повреждения → погода → правила/стюарды →
сетапы/бюджеты → полировка.

## Быстрый старт

1. Скачай Godot 4.5.1: https://godotengine.org/download
2. Открой папку проекта в Godot (файл `project.godot`)
3. Нажми F5

Управление (раскладка Phase 0, всё через Input Map и ремапится):

| Действие | Клавиши |
|---|---|
| Газ | W / ↑ |
| Тормоз | S / ↓ |
| Руль | A D / ← → |
| Нитро | Shift |
| Переключение передач | Q / E |
| Сброс машины | R |
| Камера (кокпит/chase) | V |
| Пауза | Esc / P |
| Дебаг-оверлей | F3 (скрыт по умолчанию) |

## Интерфейс и управление (0.8.0)

Игра стартует в F1-стиле меню: PLAY / TIME TRIAL / CHAMPIONSHIP / SETTINGS /
STATS + заглушки будущих режимов (онлайн, гараж). PLAY открывает Race Setup —
выбор трассы, числа кругов и сложности AI. В настройках — ассисты, пресеты
качества (low/medium/high: MSAA + разрешение 3D), громкости Master/Music/SFX и
вибрация; всё сохраняется в `user://settings.cfg`. В паузе — быстрые
настройки звука без выхода из гонки. На телефоне поверх кнопок — экранные:
стрелки руления слева, педали газа/тормоза и нитро справа, пауза сверху.
Метод рендера задан явно (`mobile`), лимитов FPS в коде нет.

## Чемпионат (0.8.0)

Полностью оффлайн-сезон вместо замороженного онлайна: NEW SEASON выбирает
число кругов чемпионата (4/6), кругов в раунде (3/5/8) и сложность AI;
календарь циклически проходит обе трассы. После каждого раунда — очки F1
(25/18/15/…), календарь с твоими результатами и таблица чемпионата; сезон
живёт в `user://championship.json` и продолжается между запусками. Результат
гонки в режиме чемпионата показывает классификацию с именами пилотов сезона
и жёлтую секцию CHAMPIONSHIP с таблицей очков; на финальном раунде —
SEASON COMPLETE с чемпионом. Сезон можно бросить (с подтверждением) и начать
новый — история старых сезонов остаётся в `user://league/results.json`.

## Гонка и Time Trial (0.6.0)

HUD в стиле F1-TV: башня позиции/круга/DRS, стенды, спид-стрип, миникарта
трассы с точками всех машин. В кокпите — процедурный руль с LED-полосой RPM
(зелёный → жёлтый → красный) и красным маркером. Нитро даёт тягию, шейдер
speed-lines и тряску камеры. Трек-лимиты: 3 срезки за круг — предупреждения
в гонке и аннулирование круга в TT. В Time Trial против тебя едет
полупрозрачный призрак твоего лучшего круга (сохраняется между сессиями).
Итоги гонки оседают в STATS: победы, подиумы, лучшие круги по трассам.

## Звук (0.5.0)

Двигатель — шесть бесшовных лупов, кроссфейд по оборотам (idle → redline);
визг шин — по слипу колёс; нитро — луп тяги пока держишь буст (в 0.5.0 нитро
даёт реальную тягу и бак с восстановлением); краш — удар металла при контакте
корпуса; старт-огни бипают на каждой лампе и «гаснут» тоном на старте; все
кнопки меню/паузы/настроек кликают, финиш — джингл. Источники и лицензии —
в [ASSETS.md](ASSETS.md) (Kenney CC0 + OpenGameArt CC0/CC-BY).

Структуру, поток данных и планы расширения — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Тесты и проверки headless (нужен Godot 4.5.1 в PATH или замените путь):

```sh
godot --headless --path . --script res://tests/run_tests.gd          # smoke-тесты
godot --headless --path . --script res://tracks/validate_tracks.gd   # валидатор трасс
```

Форматирование GDScript (gdtoolkit):

```sh
pip install gdtoolkit==4.*
gdformat -i scripts tests tracks
gdlint scripts tests tracks
```

CI прогоняет всё это на каждый push (GitHub Actions).
