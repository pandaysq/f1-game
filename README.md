# F1 Game

Простая 3D-гонка в стиле Formula 1 на движке **Godot 4.5.1**.

## Концепт

- **Режим:** Time Trial — один на трассе, гонка на лучшее время круга
- **Камера:** из кокпита (от первого лица)
- **Графика:** low-poly
- **Физика:** аркадно-симуляционная (полусим, с заносами)
- **Управление:** клавиатура — стрелки/WASD (газ, тормоз, руль), Shift — нитро

## Запуск

1. Скачай Godot 4.5.1: https://godotengine.org/download
2. Открой файл `project.godot` в Godot
3. Нажми F5

## Структура проекта

```
project.godot      # конфигурация проекта
scenes/            # сцены (трасса, болид, UI)
scripts/           # GDScript-логика (физика, камера, таймер круга)
assets/            # модели, текстуры, звуки
```
