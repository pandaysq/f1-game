# Формат трасс (v1 — черновик, реализуется в фазе 1)

Трассы — данные, не код. Один файл = одна трасса:

```
tracks/alpha_loop.json
```

## Схема (черновик к фазе 1)

```json
{
  "name": "Alpha Loop",
  "closed": true,
  "centerline": [
    { "x": 0.0, "y": 0.0, "z": 0.0, "width": 14.0, "banking_deg": 0.0 },
    { "x": 0.0, "y": 0.0, "z": -60.0, "width": 14.0, "banking_deg": 0.0 }
  ],
  "surfaces": {
    "asphalt": { "grip": 1.0 },
    "kerb": { "grip": 0.95 },
    "grass": { "grip": 0.55 },
    "gravel": { "grip": 0.45 }
  },
  "timing_lines": [
    { "name": "start_finish", "index": 0 },
    { "name": "sector_1", "index": 40 },
    { "name": "sector_2", "index": 80 }
  ],
  "spawn": { "point_index": 0, "offset_lateral": 0.0 },
  "drs_zones": [],
  "camera_points": [],
  "scenery": { "grandstands": [], "trees_density": 0.2 }
}
```

## Поля

- `centerline` — точки осевой линии по порядку обхода; `width` — ширина полотна в
  метре точки; `banking_deg` — поперечный наклон; `y` — высота (elevation).
- `surfaces` — коэффициенты сцепления относительно эталонного асфальта (1.0).
- `timing_lines` — линия по индексу сегмента центрлайны: старт-финиш обязателен,
  секторы опциональны.
- `spawn` — где стоит машина на старте Time Trial.
- `grid_slots` — необязательный список стартовых мест гонки от поула назад.
  Каждое место задаётся координатами поверхности `{x, y, z}` в метрах;
  машины развёрнуты по направлению осевой линии у старта.
- `drs_zones` / `camera_points` / `scenery` — зарезервированы фазами 2/4/9,
  валидатор их не требует.

## Правила валидации (фаза 1)

1. Замкнутость: `closed == true`, последняя точка рядом с первой (допуск).
2. Никаких самопересечений полотна (проверка на 2D-проекции).
3. `width > 3.0` во всех точках.
4. Тайминг-линии — валидные индексы внутри диапазона.
5. Отсутствие `NaN` во всех числовых полях.
